# Task040 - Массивы — найти любое повторяющееся число 3️⃣

### Задание

Напишите программу на C, которая:

1. Считывает число `n` — размер массива (n ≤ 100);  
2. Считывает `n` целых чисел и сохраняет их в массив;  
3. Находит любое число, которое встречается более одного раза;  
4. Если такое число есть, выводит его; иначе выводит `"No duplicates"`.  

---

### Пример работы программы

```text
# Ввод:
5
1 3 2 3 5
# Вывод:
Duplicate: 3

# Ввод:
4
1 2 3 4
# Вывод:
No duplicates
```

## Решение
**УЧИТЫВАЙТЕ**, что код находит первое двойное число и завершает работу сразу же после того, как это находит (это все равно подходит под условия задачи)

1) Заполняем массив:
```c
int arr[n];
  for (int i = 0; i < n; i++) {
    int val;
    scanf("%d", &val);
    arr[i] = val;
  }
```
2) Находим повторяющийся элемент:
```c 
for (int i = 0; i < n; i++) {
    int count = -1;
    for (int j = 0; j < n; j++) {
      if (arr[i] == arr[j]) {
        count++;
      }
      if (count > 0) {
        printf("Duplicate: %d\n", arr[i]);
        return 1;
      }
    }
  }
  printf("No duplicates\n");    // вызовется только если не был найден дупликат
```

Для запуска: 
```bash
gcc main.c -o main
./main
```

Для повторного запуска: `./main`
