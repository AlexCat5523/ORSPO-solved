# Task006 — Флаги компиляции (math) 🔍

Скомпилируйте программу, используя команды:

```bash
gcc main.c -o main
gcc main.c -lm -o main
./main
```

где:

* **`-lm`** — флаг для подключения математической библиотеки libm.so (link math)
---
## Задание 

* Скомпилируйте программу без флага `-lm`. Какая ошибка появилась?

* Добавьте флаг `-lm` и скомпилируйте программу снова. Успешна ли сборка?

* Запустите программу и проверьте её работу.

* Объясните, для чего нужен флаг `-lm` и почему без него возникает ошибка.


## Решение

* Если запустить первую строчку, то программа выдаст ошибку о `undefined reference to sin/cos/log/exp` (в разных строчках).
  
* Эта ошибка означает, линковщик не смог найти данные функции нигде (НЕСМОТРЯ на то, что в файле `main.c` подключена `<math>`).

* Флаг `-lm` указывает линковщику, чтобы он подключил библиотеку полностью (и нашел адреса нужных функций).

С флагом программа должна работать.
