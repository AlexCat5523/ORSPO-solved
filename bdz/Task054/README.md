# Task054 - Двухсвязный список 3️⃣

## Задание
Реализуйте двусвязный список (doubly linked list).

Необходимо реализовать функции для:

- создания нового узла списка
- добавления элемента в конец списка
- вставки элемента по заданному индексу
- удаления элемента по значению
- поиска элемента по значению
- прямого обхода списка с выводом элементов
- обратного обхода списка с выводом элементов
- освобождения всей памяти, занятой списком


## Решение
Смотрите `list.c`, все функции.
Двусвязный список - список, у которого каждый элемент списка хранит не только своё значение, но и указатель на следующий И предыдущый элементы массива

- `create_node`: функция, для создания элемента списка. Его `data` - сам элемент массива, а `next` - указатель на следующий элемент массива
- `push_back`: добавляем элемент в конец массива
- `insert_at`: Добавляем элемент в массив на определенное место
- `delete_value`: Удаляем первый встретившийся `value` из массив.
- `find`: находим элемент по значению
- `print_list`: печатаем список
- `print_list_reverse` - печатем список в обратном порядке
- `free_list`: освобождаем память списка
