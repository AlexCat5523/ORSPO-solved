# Task035 - Работа с argc / argv 3️⃣

### Задание

Написать программу, которая принимает через командную строку несколько целых чисел и выводит их сумму.  

- Используйте `argc` и `argv` для обработки аргументов командной строки  
- Если числа не переданы, вывести сообщение `"No numbers provided"`  

---

### Пример вызова программы

```bash
./main 1 2 3
```
### Результат:

```
Вывод: 6
```

### Контрольные вопросы
1. Что такое argc и argv в функции main?
2. Почему в цикле для суммирования чисел мы начинаем с i = 1, а не с i = 0?
3. Что произойдет, если пользователь не передаст аргументы?
4. Что произойдет, если аргумент командной строки не является числом?

## Решение
Чекните код, добавилось (atoi - ASCII to INT, по факту перевод строки в число):
```c
for (int i = 1; i < argc; i++) {
    sum += atoi(argv[i]);
  }
```

Ответы на контрольные вопросы:
1) `argc` - количество аргументов, передаваемых в программу через консоль, `argv` - сами аргументы. `argc` определяется автоматически исходя из размера `argv` (?)
2) Потому что argv[0] - имя программы `./main` (дальше после этого идут аргументы: argv[1...n])
3) argc = 1 и выведет "No numbers provided"
4) Если в atoi будет строка (к примеру: `atoi("abc)`, то оно станет 0: `atoi("abc") == 0`), то она не учитывается (т.е. `./main 10 abc 5` выдаст 15)

!!ЗДЕСЬ!! ПОСЛЕ `./main` могут идти различные циферки (или не идти, как хотите для проверка)

Для запуска: 
```bash
gcc main.c -o main
./main 1 2 3
```

Для повторного запуска: `./main`
