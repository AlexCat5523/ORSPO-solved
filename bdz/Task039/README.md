# Task039 - Работа с массивами 3️⃣

### Задание

Напишите программу на C, которая:

1. Считывает число `n` — размер массива (n ≤ 100);
2. Считывает `n` целых чисел и сохраняет их в массив;
3. Выводит сумму всех четных элементов массива.

---

### Прототип функции

```c
int array_sum(int arr[], int n);
```

## Решение
Всё в коде: создаем массив из n элементов, заполняем массив при помощи цикла `for`.
Вызываем функцию `array_sum`, в нем тоже проходимся по массиву циклом `for` и прибавляем к результату значение из массива, если это значение четное

Для запуска: 
```bash
gcc main.c -o main
./main
```

Для повторного запуска: `./main`
