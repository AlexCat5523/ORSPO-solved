# Task017 — Основы GDB 🔍

## Что такое GDB?

**`GDB (GNU Debugger)`** — это мощный отладчик для программ, написанных на `C`, `C++` и других языках. Он позволяет:

* Останавливать программу в любой точке

* Исследовать значения переменных

* Изменять данные во время выполнения

* Анализировать стек вызовов

* Находить причины ошибок (segmentation fault, бесконечные циклы и т.д.)

--- 

## Компиляция с отладочной информацией

```bash
gcc -g gdb_vals.c -o gdb_vals
```

где:

* `-g` — ключ, добавляющий отладочную информацию в исполняемый файл (имена переменных, строки исходного кода и т.д.)

## Запуск отладки

```bash
gdb gdb_vals
```

| Команда | 
| :--- |
| `list` | 
| `break 32` |
| `clear 32` |   
| `run` |     
| `info registers` | 
| `info locals` | 
| `ptype a` | 
| `print a` |  
| `print &a` |  
| `print sizeof(a)` |  
| `set var a = 512` |

## Задание 

* Скомпилируйте программу с ключом `-g`

* Запустите отладчик:
    ```bash
    gdb gdb_vals
    ```

* Выполните последовательно все команды из списка выше.

* Для каждой команды запишите, что она выводит и для чего предназначена.

* Исследуйте различные переменные: `a, b, c, d, d1, e, g, f, h`.

* Обратите внимание на разницу между структурой `struct str` и объединением `union code`.


## Решение
1) Компилируем
2) Запускаем
3) Выполяем все команды
4) Пояснения к командам:
   - `list`: выводит фрагмент кода тестируемой программы (~10 строк вокруг текущей позиции останова)
   - `break 32`: устанавливает точку остановка на 32-ю строчку
   - `clear 32`: удаляет точку останова на 32-й строчке
   - `run`: запуск программы с остановками на точках останова
   - `info registers`: вывод всех регистров процессора
   - `info locals`: вывод имен и значений всех локальных переменных внутри текущей функции
   - `ptype a`: тип данных переменной **a**
   - `print a`: вывод значения **a**
   - `print &a`: вывод адреса переменной **a** в оперативной памяти
   - `print sizeof(a)`: вывод размера **a** в памяти
   - `set var a = 512`: принудительно устанавливаем переменной **a** значение 512
5) Для исследования используйте команды с `ptype` по `set var `
6) `struct str` имеет размер, равный сумме её типов данных (`sizeof(a) + sizeof(b) + sizeof(c)` = 16 байт). `union code` же имеет размер такого типа данных, который имеет максимальный размер (в данном случае `sizeof(double)` = 8).

Кроме того: данные структуры в памяти распологаются *последовательно*, а данные объединения (`union`) находятся в одном месте. То есть:
* У структуры каждая переменная (a, b и c) в памяти распологаются раздельно и может иметь своё собственное значение
* У объединения при записи в любую переменную (a, b или c) будет перезаписываться **предыдущее** значение любой переменной. Пример:
```c
h.c = 3;
h.b = '2';
h.a = 1;
```

Каждое из значений будет записываться в **одно и то же место** и в результате будет какой-то мусор в зависимости от того, что записалось по адресу.
