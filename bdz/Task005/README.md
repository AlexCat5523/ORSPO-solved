# Task005 — Поэтапная компиляция 🔍 
Скомпилируйте программу последовательно с различными флагами компиляции, используя команды:

```bash
gcc -E main.c -o prMain
gcc -S main.c -o coMain.s
gcc -c main.c -o asMain.o
gcc main.o -o main
./main
```

где:

- `-E` — остановка после этапа препроцессирования

- `-S` — остановка после этапа компиляции (создание ассемблерного кода)

- `-c` — остановка после этапа ассемблирования (создание объектного файла)

- `-o` — ключ для задания имени выходного файла

## Задание

* Выполните последовательно все команды, указанные выше.

* Что происходит на каждом из этапов компиляции?

## Решение

* **ВНИМАНИЕ!!** в коде ошибка и команда для компоновки вместо `gcc main.o -o main` должна быть `gcc asMain.o -o main` (иначе выдастся ошибка об отсутствии файла main.o).

Разберем поэтапно весь процесс:
1) `gcc -E main.c -o prMain`: Препроцессинг. Раскрытие макросов, подключение всех `#include` и `#ifdef` с `#ifndef`
2) `gcc -S main.c -o coMain.s`: Компиляция. Перевод кода языка Си на команды ассемблера.
3) `gcc -c main.c -o asMain.o`: Ассемблирование (сборка). Перевод ассмеблерного кода на машинный код.
4) `gcc asMain.o -o main`: Компоновка (линковка). Линковщик указывает компилятору, где конкретно в памяти лежат переменные других файлов (если мы их включаем в нашу программу)
5) `./main`: Запускаем программу. Всё должно работать
