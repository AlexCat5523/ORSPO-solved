# Task044 - Арифметика указателей 🔍

## Задание
- Что такое арифметика указателей в языке C?
- Почему прибавление числа к указателю сдвигает его не на байты, а на элементы соответствующего типа?
- Чем отличается выражение p + 1 от выражения ((char*)p) + 1?
- Попробуйте изменить значение смещения (например, p + 10) и посмотрите, что произойдёт. Объясните результат.

## Решение
1) Арифметика указателей - операции над адресами памяти. Можно: 
    - прибавлять число к указателю
    - вычитать число из указателя
    - вычитать указатели из друг друга
    - сравнивать указатели
2) Потому что при прибавлении числа к указателю, компилятор понимает размер типа данных, на который указывают. То есть: `int *p` - указатель на тип `int`, размер `int` обычно 4 байта => при прибавлении числа к `p` прибавится именно 4 байта.
3) Тем, что мы приводит указатель `p` к указыванию на тип данных `char` (который имеет размер 1 байт) => сдвиг в первом случае произойдет на `АДРЕС + sizeof(typeof(p))`, а во втором на 1 байт.
4) Указатель вышел за границы массива и выдал рандомное значение из памяти (для этого нужно собрать и запустить программу)

Для запуска: 
```bash
gcc main.c -o main
./main
```

Для повторного запуска: `./main`
