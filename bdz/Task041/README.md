# Task041 - Найти минимум и максимум в массиве 3️⃣

### Задание

Напишите программу на C, которая:

1. Считывает число `n` — размер массива (n ≤ 100);
2. Считывает `n` целых чисел и сохраняет их в массив;
3. Выводит минимальный и максимальный элемент массива;
4. Если массив пустой (n = 0) — выводит `0 0`;
5. Если массив состоит из одного элемента — выводит его дважды.

---

### Пример работы программы

```text
# Ввод:
5
3 7 2 9 5
# Вывод:
2 9

# Ввод:
1
42
# Вывод:
42 42

# Ввод:
0
# Вывод:
0 0
```

## Решение
1) Создаем массив
```c
int arr[n];
  for (int i = 0; i < n; i++) {
    int val;
    scanf("%d", &val);
    arr[i] = val;
  }
```
2) Проверяем необходимые условия (n == 0, n == 1 и остальные)
Max и min находим почти как в ЕГЭ.

```c
if (n == 0) {
    printf("0 0");
  } else if (n == 1) {
    printf("%d %d", arr[0], arr[0]);
  } else {
    int maxi = -51325123;
    int mini = 51325123;
    for (int i = 0; i < n; i++) {
      int val = arr[i];

      if (val > maxi) {
        maxi = val;
      }
      if (val < mini) {
        mini = val;
      }
    }
    printf("%d %d", maxi, mini);
  }
```


Для запуска: 
```bash
gcc main.c -o main
./main
```

Для повторного запуска: `./main`
