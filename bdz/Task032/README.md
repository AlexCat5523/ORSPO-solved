# Task032 - Палиндром 3️⃣

### Задание

Написать программу, которая проверяет, является ли введённая строка палиндромом (читается одинаково слева направо и справа налево).

Входные данные: строка длиной до 100 символов
Выходные данные: `"Yes"` если палиндром, `"No"` если нет

---

### Прототип функции

```c
int is_palindrome(const char *s);
```

## Решение
Всё в коде: циклом `while` находим длину строки, потом проходимся циклом `for` по этой же строке и сравниваем значения с обоих сторон слова.

Для запуска: 
```bash
gcc main.c -o main
./main
```

Для повторного запуска: `./main`
