# Task029 - Наименьшее из трёх чисел 3️⃣

### Задание

Даны три целых числа. Определить **наименьшее число**.

---

### Прототип функции

```c
int min_of_three(int a, int b, int c);
```

## Решение
Все в коде: сначала для `а` проверяем, что оно меньше `b` и что `b` меньше `c` `(a <= b <= c)` (или же `(a <+ c <= b)`). Подобная же цепочка для `b`. Иначе `c`.
