# Task003 — Работа ifdef/ifndef 🔍

Скомпилируйте и запустите программу, используя команду:

```bash
gcc main.c -o main
```

## Задание

* Соберите программу. Какой результат был напечатан?

* Удалите строку `#define X`. Какой теперь результат?

* Скомпилируйте программу с флагом `-E` и изучите, что произошло.

* Объясните, почему результат изменился.

## Решение
[!Здесь скриншот решения](Result.png)

На скриншоте:

* Собираем программу

* Запускаем получившийся файл

* При помощи `nano main.c` убираем из файла `#define X`

* Собираем ещё раз, запускаем и видим другой результат (Пояснение: результат меняется из-за `#ifdef X`: если X определен,
то a = 10; если же не определен, то a = 20)

* Запускаем с флагом -E (флаг препроцессора): это этап сборки программы, при котором gcc подставляет все необходимые значения (
макросы, заголовочные файлы, выбирает Нужные ifdef и пр.)
