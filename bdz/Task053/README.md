# Task053 - Односвязанный список 3️⃣

## Задание
Реализуйте функции для взаимодействия с структурой данных - односвязанный список

Сборка и запуск программы:

```bash
make
./main
```

Сборка и запуск тестов:

```bash
make tests
./tests
```

## Решение
В файле `list.c` все функции. 
Односвязный список - список, у которого каждый элемент списка хранит не тользко своё значение, но и указатель на следующий элемент массива

- `create_node`: функция, для создания элемента списка. Его `data` - сам элемент массива, а `next` - указатель на следующий элемент массива
- `push_back`: добавляем элемент в конец массива
- `insert_at`: Добавляем элемент в массив на определенное место
- `delete_value`: Удаляем первый встретившийся `value` из массив.
- `find`: находим элемент по значению
- `print_list`: печатаем список
- `free_list`: освобождаем память списка
