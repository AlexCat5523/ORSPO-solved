# Task057 - Поиск циклов в списке 4️⃣

## Задание
Реализуйте функцию проверки наличия цикла в односвязном списке. Используйте алгоритм "черепаха и заяц" (Floyd's cycle detection algorithm) для эффективного поиска циклов.

## Решение
Алгоритм "черепаха и заяц":
1) Черепаха смещается на один элемент за шаг
2) Заяц смещается на два элемента за шаг
3) Если список - циклический (т.е. последний элемент списка указывает на самый первый элемент списка) заяц догонит черепаху, если же заяц достиг NULL - список не циклический

В `main.c` реализована только функци *проверки* наличия цикла. В самом алгоритме есть ещё функция поиска начала цикла, она в данном коде не сделана
