# Task002 — Компиляция программы из нескольких файлов 🔍 
Скомпилируйте и запустите программу, состоящую из нескольких файлов используя команды

```bash
gcc main.c lib.c -o main
./main
```

# Задание

* Скомпилируйте программу и убедитесь, что она работает.

* Попробуйте включить заголовочный файл `lib.h` несколько раз в файле `main.c` (добавьте директиву `#include "lib.h"` ещё раз).

* Скомпилируется ли программа теперь?

* Объясните, почему так происходит. Что можно добавить в заголовочный файл, чтобы избежать проблем при многократном включении?

# Решение

* После выполнения команды в первый раз все сработает.

* Затем необходимо каким-либо образом добавить в файл `main.c` **ЕЩЁ** один `#include "lih.h"`. Для этого можно воспользоваться
```bash
nano main.c
```

Откроется редактор для этого файла. В нем сделать изменения, нажать `Ctrl + S`, затем `Ctrl + X`.

* Затем запустить код из задания ещё раз. Программа должна скомпилироваться, потому что:
**Язык C поддерживает многокротное _объявление_ функций, но не их _определение_. Объявление не имеет тела функции.**

* Избежать многократные включений можно добавление следующих строк в `lib.h`: 
```bash
#ifndef LIB_H
#define LIB_H

// Здесь идет код lib.h

#endif // LIB_H
```
