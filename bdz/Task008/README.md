# Task008 — Clang-format и Clang-tidy 🔍

## Установка инструментов

```bash
sudo apt-get install clang-format clang-tidy
```
где:

* **clang-format** — инструмент для автоматического форматирования кода

* **clang-tidy** — инструмент для статического анализа кода (поиск ошибок, проверка стиля)
---
## Основные команды

```bash
# Форматирование файла (флаг -i означает "in-place" — изменения сразу в файле)
clang-format -i main.c

# Запуск статического анализа со всеми проверками
clang-tidy main.c -checks=*

# Запуск статического анализа с указанием стандарта языка
clang-tidy main.c -- -std=c11
```
--- 

## Задание  

* Установите `clang-format` и `clang-tidy` с помощью команды выше.

* Выполните форматирование программы: `clang-format -i main.c`. Что изменилось в коде?

* Запустите статический анализ: `clang-tidy main.c -checks=*`. Какие ошибки и предупреждения найдены?

* Запустите анализ с указанием стандарта C11: `clang-tidy main.c -- -std=c11`. Появились ли новые предупреждения?

* Исправьте все найденные ошибки в программе.
  
## Решение

* После форматирования программы код стал внешне более структурированным.

* Большая часть предупреждений вылезает о `magic numbers`: числовые значения, которые взяты как бы из "ниоткуда" (Пример: `int x = 5`. 5 будет магическим числом - потому что причина почему там именно *5* - непонятна. Анализатор предлагает все такие числа заменить константы (считается, что если константы определены программистом, то они должны быть именно такими по какой-то причине. *ВАЖНО*: магические числа - не ошибка и с ними программа скомпиллируется, но анализатор кода ругаться на них будет )

* Также есть предупреждение о выходе за границы `arr[100]`.

* При указании стандарта С11 ошибок стало меньше

* Исправленный код:

По поводу кода: если использовать `enum` вместо `#define`, то остается только одна ошибка про `#include <stdio.h>`, которую невозможно исправить (если не удалять `printf` конечно, хотя я сомневаюсь, что это подразумевается заданием).

Если же все-таки это подразумевается: удалить первую строчку, `printf("Hello");` и весь if.


```C
#include <stdio.h>

enum {
    X = 5,      // сделаем x константой
    LEN = 100,  // сделаем длину списка константой
    VAL = 20,   // сделаем значение, которое мы присваиваем в 13-й строчке, константой
    INDEX = 5   // индекс для списки в 13-й строчке
};

int main()
{
	int xxx = X;
	int arr[LEN];
	arr[INDEX] = VAL;
	printf("Hello");
	if (xxx > 3) {
		printf("World");
	}
	return 0;
}
```
