# Task043 - Указатели 🔍

## Задание
- Что такое указатели ?
- Как работает const квалификатор для указателей ?
- Попробуйте скомпилировать программу, в случае, если она не компилируется, то узнайте причину и исправьте ошибку
- Где в этом приложение находится undefined behavior ?
- Есть ли в этой программе SEGFAULT, если он есть, то почему, если его нет, то также почему ?

## Решение
1) Указатель - переменная, хранящая адрес, по которому располагается другая переменная в памяти:
```c
int val = 5;    // создаем переменную типа int
int* ptr = &val;    // ptr теперь указывает на адрес val в памяти (& - указывает на то, что берем адрес)
printf("%d", *ptr); // в данном контексте * - разыменовывание указателя, т.е. мы берем значение, которое лежит по адресу указателя (т.е. val)
```
2) Запрещает менять адрес, на который ссылается указатель
3) Всё компилируется, но в `main.c` есть закомментированные строки, при раскоментировании которых программа не соберется (`gcc main.c -o main`, затем `./main`)
4) 27-28 строки:
```c
int *uninitialized;
printf("%d\n", *uninitialized);
```

Мы пытаемся разыменовать указатель, которому не присвоили значение адреса (простыми словами: пытаемся узнать значение переменной, у которой нет значения)
5) Есть из-за нулевого указателя, потому что доступ по адресу NULL запрещен
