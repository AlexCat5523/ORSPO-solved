# Task025 - Деление двух чисел 3️⃣

### Задание

Напишите программу на C, которая:

- считывает два целых числа: числитель и знаменатель;
- вычисляет целочисленное деление числителя на знаменатель;
- выводит результат на экран.

Необходимо учесть проверку деления на 0

## Решение
* Посмотрите код в main.c (учитывайте, что при делении на 0 ВЫВЕДЕТСЯ 0)

* Введите в wsl (программа должна запуститься):

```bash
gcc main.c -o main
./main
```

* Для повторного запуска введите `./main`
