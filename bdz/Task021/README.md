# Task021 — Типы данных 🔍 

## Описание задачи

Скомпилируйте и запустите программу:

```bash
gcc main.c -o main
./main
```

Объясните результат работы. 

Раскомментируйте строки и объясните результат вывода числа на экран. Измените тип числа на double. 
Изменился ли вывод?

## Решение

Из-за переполнения float результат округлится в 0
У double больше бит => нет переполнения
