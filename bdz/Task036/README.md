# Task036 - Функция для решения квадратного уравнения 3️⃣

### Задание

Напишите программу на языке C, которая решает квадратное уравнение:  

ax^2 + bx + c = 0

где `a`, `b` и `c` — действительные числа, введённые пользователем.  

- Функция должна принимать коэффициенты `a`, `b`, `c` и возвращать количество действительных корней.
- Если есть корни, функция записывает их через указатели `x1` и `x2`.

---

### Прототип функции

```c
int solve_quadratic(double a, double b, double c, double *x1, double *x2);
```

## Решение
Решаем через дискриминант и записываем в корни x1 и x2.

В main добавлены две переменные x1 и x2, которые передаются в функцию `solve_quadratic`

*Флаг -lm для подключения math.h*
Для запуска: 
```bash
gcc main.c -lm -o main
./main
```

Для повторного запуска: `./main`
