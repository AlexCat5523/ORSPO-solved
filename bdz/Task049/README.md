# Task049 - Динамический одномерный массив 3️⃣

## Задание
Реализуйте функции (случайная генерация, вывод, поиск максимального элемента) для работы с одномерным динамическим массивом, состоящим из дробных чисел.

## Решение
Реализовано в `main.c`

`malloc` - динамическое выделение памяти

`double* lis = (double*)malloc(n * sizeof(double));`: malloc выделяет память в размере n * sizeof(double), затем преобразует тип данных в указатель (`(double*)`) и это присваивается указателю lis.
