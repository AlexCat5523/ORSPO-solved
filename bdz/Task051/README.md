# Task051 - Функция increase_array 4️⃣

## Задание

Реализуйте функцию increase_array со следующей сигнатурой:

```c
void increase_array(int **a, int n, int n_new)
```

Функция модифицирует массив, изменяя его размер с n до n_new.

## Решения
Функция print_arr была добавлена для проверки, что массив действительно был увеличен в размерах.

`realloc` - увеличивает размер существующего массива до необходимово (`realloc(ptr, new_size)`)
